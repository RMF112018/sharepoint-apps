# Add to Page — HBI Form Demo

## Who is this for?
Site editors on kmeholding.sharepoint.com.

## Steps
1. Navigate to your SharePoint site page and click “Edit”
2. Click the “+” to add a new web part
3. Search for: "HBI Form Demo"
4. Select the web part and place it on the page
5. (Optional) Configure the Description property in the property pane
6. Click “Publish” to make changes live
